About This Course

This website is a simple GitHub tutorial and practice project. The goal is to learn the basic Git and GitHub workflow by editing this website and tracking those changes with Git.

What is Git?

Git is a version control system used to track changes in files. It allows developers to save versions of their work, create branches, and collaborate with other developers.

A Git project is usually stored inside a repository.

What is GitHub?

GitHub is an online platform used to host Git repositories. It makes it easier to store projects online, collaborate with others, review code, and manage software projects.

Some important GitHub features include:

  • Repositories
  • Commits
  • Branches
  • Pull Requests
  • Issues
  • GitHub Pages

Basic Git Commands

Check Git Version

git --version

Initialize a Repository

git init

Check Repository Status

git status

Add Files

git add .

Create a Commit

git commit -m "Add initial website"

View Commit History

git log

Create a Branch

git switch -c new-feature

Switch Branches

git switch main

Connect to GitHub

git remote add origin YOUR_REPOSITORY_URL

Push to GitHub

git push -u origin main

Pull Changes

git pull

Practice Tasks

Try making changes to this website while learning Git and GitHub.

  1. Create a new Git repository.
  2. Add this index.html file.
  3. Create your first commit.
  4. Create a GitHub repository.
  5. Push the project to GitHub.
  6. Create a new branch.
  7. Change the heading or page content.
  8. Commit your changes.
  9. Push the branch to GitHub.
  10. Create a pull request.
  11. Merge the pull request into main.
  12. Try opening and closing an Issue.
  13. Publish the website using GitHub Pages.
